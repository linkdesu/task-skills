# AGENTS.md

This file defines repository conventions for humans and AI agents working in this project.

## Glossary

- Skill: A reusable task guide stored as a directory under `skills/<skill-name>/`, with `SKILL.md` as the entry file.
- Skill Index: The section in `README.md` that lists all published skills with links.

## Rules

1. WHENEVER `README.md` is updated, all translation READMEs must be updated in sync, except the user explicitly requests a language-specific change.
2. WHENEVER a new skill is added under `skills/`, `README.md` Skill Index must be updated in the same change.
